# Connect Four Game

Welcome to the Connect Four game project! This project is a classic Connect Four game implemented using Python and Pygame. The game allows a player to compete against each other to connect four of their pieces in a row, either horizontally, vertically, or diagonally.

## Project Overview

Connect Four is a two-player board game in which players take turns dropping colored discs into a grid. The objective is to be the first to connect four of one's own discs in a row. This implementation uses Python and the Pygame library to create a graphical version of the game.

## Key Features

- **Two-Player Mode**: Play against another player on the same machine.
- **Graphical Interface**: Interactive GUI with Pygame for a visually appealing experience.
- **Game Logic**: Handles game rules, winning conditions, and turn management.

## Getting Started

To get started with this project, follow these steps:

### 1. **Clone the Repository**

Clone the repository to your local machine:

`git clone https://github.com/your-username/connect-four-game.git`

`cd connect-four-game`

### 1. **Set up the environment**
Ensure you have Python and Pygame installed. You can install Pygame using pip:

pip install pygame
### 3. **Run the Game**
To start the game, execute the connect_four.py script:

python connect_four.py

### 4. **Play the Game**
Follow the on-screen instructions to play the game. Click on the columns to drop your discs and try to connect four of your discs in a row to win.
